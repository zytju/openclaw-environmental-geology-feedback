# 《环境地质学》学生本地课程包

推荐接入本人 **DeepSeek API**，默认模型为 deepseek-flash。本包不含模型密钥，不含教师Agent，不是公共课程网站。

## 快速使用

1. 先安装并确认 OpenClaw **2026.7.1-2**。这是本机实际验证版本；不能把其他版本安装成功当作课程验收通过。
2. 从教师提供的ZIP解压到本机普通文件夹。不要在压缩包内直接运行。
3. Windows双击“开始使用.cmd”；macOS按图文指南在终端运行“bash 开始使用.command”。或在该目录运行“node course.mjs start”。
4. 浏览器会打开本机页面。先运行课程自检，再输入本人DeepSeek API Key，点击“连接测试”。
5. 只在出现“课程连接测试成功”后粘贴报告题目、正文及书目。草图与证据卡可全部留空。
6. 获得完整六维后，回原论文核对、独立修订。报告必交，截图选交；只通过教师指定问卷星提交。

主作业为至少2篇研究性论文、正文2000字以上，限三峡库区滑坡及灾害链。建议中文、英文各1篇。AI拓展不计入平时成绩，按教师任务通知执行。

## 保存位置和退出

课程安装到本人“文稿/Documents”下的 EG-Midterm-2026-20261109_1452；已有个人OpenClaw配置不被修改。再次启动核验文件，不覆盖未知目录。若文件损坏，请保留旧目录，按教师说明用新目录安装，不把旧目录上传GitHub。

API Key仅在启动进程内存中保留，关闭后重新输入；OpenClaw可能在本机保存会话及模型运行记录。正文发送至DeepSeek等本人选定的模型服务。不要使用教师Key或把个人Key、报告、封面、会话目录提交到公共仓库。

关闭启动终端或按Ctrl+C退出。每次启动使用新的随机本机入口；每次反馈使用新的OpenClaw会话。修订时需重新提交当前完整正文，不能假定Agent记住上轮。

本机真实OpenClaw已验证配置及角色加载；DeepSeek默认接入需本人有效Key与余额才能完成真实连接及六维验收。教师本机GPT验证仅证明所测GPT路径，不能替代DeepSeek实测。Windows运行脚本和离线测试的结果需另看教师验收记录，不能推断所有学生电脑均已通过。

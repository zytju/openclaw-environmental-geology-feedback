# 隐私、权限与会话资料

公开仓库只含原创规则、代码、模板和标记为模拟的样例。身份映射、学生原件、intake、AI反馈、终审、发放清单、问卷细项和真实日志均在教师私有目录。600/700权限不代表加密，也不证明无法被系统其他授权进程访问。

profile同样必须在公开仓库之外。stage和verify_profile拒绝仓库内部路径。agentDir、工作区和会话沙箱分开，工具只允许read，禁用执行、写入、浏览、消息、跨会话与提权；这些是配置要求，实际阻断仍须专门验收。

OpenClaw可能在profile中保留请求、会话、转录、状态数据库、缓存、日志及备份。本版不写死跨版本的会话库文件名。正式小样本前后由教师核对实际版本产生的文件与位置，并把profile整体视为含学生材料的私有归档。仅删除批处理JSON不等于删除会话副本。workspace只读也不限制宿主进程在状态目录写入必要运行状态，须分别核查。

request.json使用私有临时目录与600权限，用后删除；CLI stdout经解析后只保留通过校验的结构化结果及允许的数值用量。无效原始响应和stderr默认不落盘。系统崩溃、服务方留存及备份中的副本不由临时文件删除保证消除。

保留期限由教师按学校教学、结题与伦理要求确认，填写私有保管记录：位置、访问人、用途、保留至何日、备份及销毁责任人。到期先确认结题归档和申诉需求，再停止该独立实例，按版本清理私有profile、运行结果、临时残留与备份并记录操作。不要执行未经核对的整目录删除命令；不删除用户既有OpenClaw状态。

固定输入协议不执行报告附带代码、不访问输入链接。提示注入和隐私正则仅初筛，普通姓名和学号仍可能漏检，教师逐份核查。收窄误报规则不等于防注入已完备。真实外部模型访问要核查授权、服务条款、数据路由和留存；工具容器断网不表示模型推理留在本机。

发布前人工检查最终包与Git差异，排除学生内容、身份表、真实会话、密钥、学校原件、未获许可的监测资料。gitignore不能代替检查。当前没有部署或上传GitHub。

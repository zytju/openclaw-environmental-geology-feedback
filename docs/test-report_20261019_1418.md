## 经复现修复的边界

未知来源不再变成无编号的invalid记录，而是保留S编号和gate、交教师登记。完整报告和片段必须声明范围；not_in_scope无等级和问题。absent不能建议3级，supported不能建议0级；只有句号的引文被拒绝，短的有效术语仍可引用。正常“监测预警系统提示”等用语不再被误报；明显泄露指令仍暂缓。

教师复核问题不能串到其他维度。发放包只含人工选定的学生问题，teacher_check不能发放；修订门槛只核对实际发放清单。AI反馈质控计数与教师确认的学生问题分别汇总，按阶段去重并排除范围外，真实受益人数仍为空。

## 独立试用的专业边界

学生端在五个声明维度给出3条问题，防治为not_in_scope；教师端指出待审反馈反向解读C03、截断语气、最高档无依据及遗漏，同时承认材料中已有的条件与假设边界。两次试用均由独立gpt-6.1-sol xhigh直接执行，不经过OpenClaw，没有真实学生或真实教师签认。

观察中仍有专业校准问题：待检命题与最终立场、纯文字证据等级、元数据与片段叙述的范围冲突。原始A/E材料的精确结构化锚点、教师新增问题及改写尚未完全自动化。公开合成输出、摘要和对应输入均在case-study/examples与tests/fixtures；完整原始执行日志保存在私有审计目录。

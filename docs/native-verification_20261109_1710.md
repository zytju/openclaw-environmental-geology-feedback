# 学生原生OpenClaw课程包验收记录（2026-11-09）

## 结论与适用范围

本轮完成学生本地课程启动包，不依赖教师域名或服务器。实际通过教师电脑现有OpenClaw及GPT授权验证学生反馈路径；默认推荐的DeepSeek API尚无真实Key验收，不能据此宣布66名学生已经可用，也没有已经实测开放的全班公共URL。

本地学生在各自电脑及系统账号安装，各用本人模型账号。课程包只配置eg-student-feedback、eg-authenticity-anchor及eg-report-feedback，工具全部禁用；不会配置教师Agent、向学生分发教师凭据，或提供他人材料的读取接口。学生拥有自己电脑的管理权限，本地包不能强制阻止电脑所有者改装程序。GitHub公开的教师历史代码不等于授予教师运行权限。

# 10月23日课堂实施计划

计划日期改为2026年10月23日，原10月30日安排作废。66人为本学期课程人数，尚不是实际参与或受益人数。课堂和课后活动均按实际发生时间记录。

## 课前10月19日至22日

先完成本版离线复现、教师量规校准和材料模板试填。教师在试跑前确定专业验收样本与通过标准。用户批准后，另用全新私有profile进行合成材料的真实模型与权限验收，再决定能否处理匿名真实材料。确认实际模型和外部数据流向，完成必要告知。录制课堂视频须按学校要求取得相应同意。

对材料转换、来源核对、两端模型和人工终审分别计时。全班模型时长用各角色实测平均时间分别乘66估算，另加人工、失败和重试时间；不承诺一节课完成132次调用，也不从mock速度推算费用或真实耗时。

若到10月22日仍未完成真实链路、权限和专业验收，10月23日按同一案例与六维量规开展教师反馈和模拟演示，不把模拟输出当真实AI介入；保留初稿，待验收后再决定AI反馈环节。实际AI覆盖范围据实记载，不预填66份已处理。

## 10月23日课堂

教师介绍资料身份和任务范围。学生先独立完成案例分析，提交报告、原始分析和证据卡；先保存初稿，再提供反馈。明确首次蓄水、周期水位变化、文献模型与现场证据的区别，以及涌浪链的假设性质。学生可以有据地拒绝AI建议。

可以课堂收集材料、课后按教师核查顺序批处理；不要为追求课堂展示跳过来源和专业审核。保留独立分析活动或短案例任务，为后续能力判断提供与接受度不同的证据。

## 课后建议窗口

10月24日至26日：完成已获准的批处理、教师终审和反馈发放；具体耗时据实登记。

10月27日至29日：学生自主修订，提交采纳/拒绝理由；如实际安排变化，记录真实日期，不倒填。

后续收集新问卷、作品前后对照和独立任务结果。问卷须保存原题、题型、原始频数与每题有效分母，不从四舍五入百分比反推人数。课前素材中的“绝大多数希望计入成绩”“仅听说过”等措辞待原始题目核查，不直接沿用。

## 成效与结题证据

分别记录课程人数、交初稿人数、材料合格人数、AI输出数、人工终审数、实际收到反馈人数、修订人数、问卷有效数与独立任务有效数，不能互换。

接受度改变不等于专业能力提高，作品修改也不能单独证明独立能力提高。前期项目200余人、98%和92%不作为本项目结果。真实监测文件未取得前，只开展文献机制辨析或明确标记的模拟训练。

学校现有通知要求11月30日前报送；结题表预填11月15日不自动成为已经完成的日期。论文发表、云Gateway是否调整、经费实际支出和项目类别名称由负责人核实；投稿或录用不能自行等同已发表。
